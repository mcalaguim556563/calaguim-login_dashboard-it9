# Login and Dashboard App

This is a simple web app with Login, Register, and Dashboard pages.

## Files

- login.html
- register.html
- dashboard.html
- style.css
- README.md

# User Manual

## 1. Open the app

1. Download this project.
2. Open the file **login.html** in your browser.

## 2. Register

1. Click **Register here**.
2. Fill in the form:
   - Full Name
   - Username
   - Email
   - Password
   - Confirm Password
3. Click **Register**.
4. It will go back to the Login page.

## 3. Login

1. Type your Username and Password.
2. Click **Login**.
3. You will see the Dashboard page.

## 4. Dashboard

You can see the table with user info.

## 5. Logout

Click **Logout** to go back to Login.

## Simple Page Flow

Register -> Login -> Dashboard -> Logout -> Login
