# calaguim-login_dashboard-it9

## User Manual

### Overview
This project is a simple Login → Dashboard system with a Registration page.

### Pages
- **login.html** – user login form  
- **register.html** – user registration form  
- **dashboard.html** – simple table dashboard  

### How to Use
1. Open `register.html`
2. Fill in the registration form  
3. Click **Register** (redirects to `login.html`)  
4. Enter username and password  
5. Click **Login** to view the dashboard  
6. Click **Logout** to go back to login page  

### Notes
- This project is static HTML/CSS only  
- No database or backend is used
